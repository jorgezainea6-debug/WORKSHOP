# Academic Data Analysis - University Performance

## Project Overview

The institution has identified a decline in student academic performance and aims to better understand the underlying causes. This project focuses on analyzing historical academic data, including:

Student information  
Course enrollment  
Attendance records  
Exam results  
Faculty and departmental data  

The goal is to generate insights, identify improvement opportunities, and propose strategies to enhance academic outcomes and administrative efficiency.

## Objectives

Analyze student performance across courses  
Evaluate the relationship between attendance and grades  
Identify performance patterns and risk groups  
Assess faculty workload and effectiveness  
Detect data quality issues (nulls, duplicates)  
Provide actionable recommendations

Performance classification

```sql
SELECT 
MARKS, 
CASE 
WHEN MARKS < 60 THEN 'DEFICIENTE' 
WHEN MARKS BETWEEN 60 AND 80 THEN 'MEDIO' 
WHEN MARKS > 80 THEN 'EFICIENTE' 
END AS PERFORMANCE_LEVEL 
FROM AD.AD_EXAM_RESULTS;
```

Students per performance level

```sql
SELECT 
CASE 
WHEN MARKS < 60 THEN 'DEFICIENTE' 
WHEN MARKS BETWEEN 60 AND 80 THEN 'MEDIO' 
WHEN MARKS > 80 THEN 'EFICIENTE' 
END AS PERFORMANCE_LEVEL, 
COUNT(*) AS TOTAL_STUDENTS 
FROM AD.AD_EXAM_RESULTS 
GROUP BY 
CASE 
WHEN MARKS < 60 THEN 'DEFICIENTE' 
WHEN MARKS BETWEEN 60 AND 80 THEN 'MEDIO' 
WHEN MARKS > 80 THEN 'EFICIENTE' 
END;
```

Chart query

```sql
SELECT 
ATTENDANCE_LEVEL, 
SUM(CASE WHEN PERFORMANCE_LEVEL = 'DEFICIENTE' THEN 1 ELSE 0 END) AS DEFICIENTE, 
SUM(CASE WHEN PERFORMANCE_LEVEL = 'MEDIO' THEN 1 ELSE 0 END) AS MEDIO, 
SUM(CASE WHEN PERFORMANCE_LEVEL = 'EFICIENTE' THEN 1 ELSE 0 END) AS EFICIENTE 
FROM ( 
SELECT 
CASE 
WHEN A.NO_OF_DAYS_OFF <= 10 THEN 'ALTA_ASISTENCIA' 
WHEN A.NO_OF_DAYS_OFF BETWEEN 11 AND 20 THEN 'MEDIA_ASISTENCIA' 
ELSE 'BAJA_ASISTENCIA' 
END AS ATTENDANCE_LEVEL, 

CASE 
WHEN R.MARKS < 60 THEN 'DEFICIENTE' 
WHEN R.MARKS BETWEEN 60 AND 80 THEN 'MEDIO' 
ELSE 'EFICIENTE' 
END AS PERFORMANCE_LEVEL 

FROM AD.AD_STUDENT_ATTENDANCE A 
JOIN AD.AD_EXAM_RESULTS R 
ON A.STUDENT_ID = R.STUDENT_ID 
) 
GROUP BY ATTENDANCE_LEVEL 
ORDER BY ATTENDANCE_LEVEL;
```

Courses by department (detailed)

```sql
SELECT  
D.DEPARTMENT_ID, 
D.DEPARTMENT_NAME AS DEPARTAMENTO, 
D.HOD AS JEFE_DE_DEPARTAMENTO, 
C.COURSE_NAME AS CURSO, 
C.COURSE_ID AS COD_CURSO,
```

Faculty, courses and department

```sql
SELECT  
F.FIRST_NAME || ' ' || F.LAST_NAME AS PROFESOR, 
D.DEPARTMENT_NAME AS DEPARTAMENTO, 
F.SALARY AS SALARIO, 
J.JOB_TITLE AS CARGO, 
C.COURSE_NAME AS CURSO, 
C.COURSE_ID AS COD_CURSO, 
COUNT(*) OVER (PARTITION BY F.FACULTY_ID) AS TOTAL_CURSOS_DEL_PROFESOR 
FROM AD.AD_FACULTY_DETAILS F 
JOIN AD.AD_FACULTY_COURSE_DETAILS FC ON F.FACULTY_ID = FC.FACULTY_ID 
JOIN AD.AD_COURSE_DETAILS C ON FC.COURSE_ID = C.COURSE_ID 
JOIN AD.AD_DEPARTMENTS D ON C.DEPARTMENT_ID = D.DEPARTMENT_ID 
JOIN AD.AD_JOBS J ON F.JOB_ID = J.JOB_ID 
ORDER BY TOTAL_CURSOS_DEL_PROFESOR DESC;
```

Faculty workload

```sql
SELECT  
F.FACULTY_ID, 
F.FIRST_NAME || ' ' || F.LAST_NAME AS PROFESOR, 
D.DEPARTMENT_NAME AS DEPARTAMENTO, 
F.SALARY AS SALARIO, 
J.JOB_TITLE AS CARGO, 
C.COURSE_NAME AS CURSO_ASIGNADO, 
C.COURSE_ID AS COD_CURSO, 
COUNT(*) OVER (PARTITION BY F.FACULTY_ID) AS TOTAL_CURSOS, 
ROUND(F.SALARY / NULLIF(COUNT(*) OVER (PARTITION BY F.FACULTY_ID), 0), 2) AS SALARIO_POR_CURSO_APROX 
FROM AD.AD_FACULTY_DETAILS F 
JOIN AD.AD_FACULTY_COURSE_DETAILS FC ON F.FACULTY_ID = FC.FACULTY_ID 
JOIN AD.AD_COURSE_DETAILS C ON FC.COURSE_ID = C.COURSE_ID 
JOIN AD.AD_DEPARTMENTS D ON C.DEPARTMENT_ID = D.DEPARTMENT_ID 
JOIN AD.AD_JOBS J ON F.JOB_ID = J.JOB_ID;
```

Faculty job titles

```sql
SELECT  
F.FACULTY_ID, 
F.FIRST_NAME, 
F.LAST_NAME, 
J.JOB_TITLE 
FROM AD.AD_FACULTY_DETAILS F 
JOIN AD.AD_JOBS J ON F.JOB_ID = J.JOB_ID;
```

Faculty per department

```sql
SELECT  
D.DEPARTMENT_ID, 
D.DEPARTMENT_NAME, 
D.HOD AS JEFE_DE_DEPARTAMENTO, 
COUNT(DISTINCT F.FACULTY_ID) AS NUMERO_PROFESORES, 
COUNT(FC.COURSE_ID) AS TOTAL_CURSOS_ASIGNADOS, 
ROUND(COUNT(FC.COURSE_ID) / NULLIF(COUNT(DISTINCT F.FACULTY_ID), 0), 2) AS PROMEDIO_CURSOS_POR_PROFESOR, 
MIN(F.SALARY) AS SALARIO_MINIMO, 
MAX(F.SALARY) AS SALARIO_MAXIMO, 
AVG(F.SALARY) AS SALARIO_PROMEDIO 
FROM AD.AD_DEPARTMENTS D 
LEFT JOIN AD.AD_COURSE_DETAILS C ON D.DEPARTMENT_ID = C.DEPARTMENT_ID 
LEFT JOIN AD.AD_FACULTY_COURSE_DETAILS FC ON C.COURSE_ID = FC.COURSE_ID 
LEFT JOIN AD.AD_FACULTY_DETAILS F ON FC.FACULTY_ID = F.FACULTY_ID 
GROUP BY D.DEPARTMENT_ID, D.DEPARTMENT_NAME, D.HOD 
ORDER BY PROMEDIO_CURSOS_POR_PROFESOR DESC;
```

## 3. Integrated Analysis

Full academic dataset

```sql
SELECT  
s.STUDENT_ID, 
s.FIRST_NAME AS STUDENT_NAME, 
s.EMAIL_ADDR, 
s.STUDENT_REG_YEAR, 
c.COURSE_ID, 
c.COURSE_NAME, 
d.DEPARTMENT_ID, 
d.DEPARTMENT_NAME, 
f.FACULTY_ID, 
f.FIRST_NAME || ' ' || f.LAST_NAME AS FACULTY_NAME, 
f.SALARY, 
et.EXAM_TYPE, 
et.EXAM_NAME, 
er.MARKS, 
att.NO_OF_WORKING_DAYS, 
att.NO_OF_DAYS_OFF, 
att.ELIGIBILITY_FOR_EXAMS 
FROM AD.AD_STUDENT_DETAILS s 
LEFT JOIN AD.AD_STUDENT_COURSE_DETAILS sc ON s.STUDENT_ID = sc.STUDENT_ID 
LEFT JOIN AD.AD_COURSE_DETAILS c ON sc.COURSE_ID = c.COURSE_ID 
LEFT JOIN AD.AD_DEPARTMENTS d ON c.DEPARTMENT_ID = d.DEPARTMENT_ID 
LEFT JOIN AD.AD_FACULTY_COURSE_DETAILS fc ON c.COURSE_ID = fc.COURSE_ID 
LEFT JOIN AD.AD_FACULTY_DETAILS f ON fc.FACULTY_ID = f.FACULTY_ID 
LEFT JOIN AD.AD_EXAM_RESULTS er ON s.STUDENT_ID = er.STUDENT_ID AND c.COURSE_ID = er.COURSE_ID 
LEFT JOIN AD.AD_EXAM_DETAILS ed ON er.EXAM_ID = ed.EXAM_ID 
LEFT JOIN AD.AD_EXAM_TYPE et ON ed.EXAM_TYPE = et.EXAM_TYPE 
LEFT JOIN AD.AD_STUDENT_ATTENDANCE att ON s.STUDENT_ID = att.STUDENT_ID;
```

Records with null values

```sql
SELECT * 
FROM (...) 
WHERE STUDENT_NAME IS NULL 
OR COURSE_NAME IS NULL 
OR FACULTY_NAME IS NULL

```

Duplicate records

```sql
SELECT  
STUDENT_ID, 
COURSE_ID, 
EXAM_TYPE, 
COUNT(*) AS REPETIDOS 
FROM (...) 
GROUP BY STUDENT_ID, COURSE_ID, EXAM_TYPE 
HAVING COUNT(*) > 1;
```

Faculty average performance

```sql
SELECT  
FACULTY_NAME, 
ROUND(AVG(MARKS),2) AS PROMEDIO 
FROM (...) 
GROUP BY FACULTY_NAME 
ORDER BY PROMEDIO ASC;
```
